# x4 Optimizer

App com interface gráfica (WPF) que aplica o modo "gráfico de batata" no Roblox editando o
`GlobalBasicSettings_13.xml` (sem FastFlags, sem injeção). Faz backup do original e permite restaurar.

## Compilar no GitHub
1. Suba estes arquivos para um repositório.
2. Aba **Actions** > workflow **Build x4 Optimizer** (roda sozinho a cada push).
3. Abra a execução e baixe o artefato **x4Optimizer-win-x64** (contém o `x4Optimizer.exe`).

A lógica de edição do XML é baseada no projeto 66mods (MIT) - veja `LICENSE-66mods.txt`.
